# vidcull

로컬에 쌓인 대용량 영상 라이브러리에서 **중복 영상을 찾아 정리**하는 데스크톱 도구.

백그라운드 데몬이 폴더를 인덱싱하고, 데스크톱 앱에서 중복 그룹을 썸네일로 확인하며 안전하게 삭제한다. 영상을 옮기거나 복사하지 않고 **있는 자리에서 그대로** 분석한다.

## 무엇을 찾나

파일이 똑같은 경우뿐 아니라, **눈으로 보면 같은 영상인데 파일은 다른** 경우까지 찾는다.

- **완전 동일** — 바이트까지 같은 파일
- **재인코딩 / 포맷 변환** — 코덱·비트레이트·컨테이너만 바뀐 같은 영상
- **크기·크롭·워터마크 변형** — 리사이즈, 잘라내기, 로고 삽입
- **부분 클립** — 긴 원본에서 잘라낸 짧은 영상이나 하이라이트 편집본

## 특징

- **조용한 백그라운드 동작** — 별도 데몬이 인덱싱을 맡고, 컴퓨터가 한가할 때 위주로 돌도록 CPU·디스크 사용을 스로틀링한다.
- **끊겨도 이어서** — 파일이 추가·변경되면 자동 반영하고, 중단된 스캔은 다음에 이어서 진행한다.
- **HDD·NAS 친화** — 순차 읽기를 우선하고 디스크 시크를 최소화한다.
- **되돌릴 수 있는 삭제** — 삭제는 최종 확인 후 OS 휴지통으로 보내며, 실수로 지워도 복원을 감지한다.
- **FFmpeg는 선택** — 흔한 코덱(H.264/H.265, MP4·MKV)은 내장 처리로 FFmpeg 없이 동작한다. AV1·VP9 등 일부 코덱이나 손상 파일 처리에만 FFmpeg를 쓴다.

## 동작 방식

```
┌──────────────────────────┐     로컬 IPC      ┌──────────────────────────┐
│  데스크톱 앱 (Tauri)      │ ◄──────────────► │  백그라운드 데몬          │
│  중복 그룹 검토·삭제 UI   │                  │  스캔 → 분석 → 지문 생성  │
│                          │                  │  → 중복 매칭 → 썸네일     │
│                          │                  │  (SQLite에 저장)          │
└──────────────────────────┘                  └──────────────────────────┘
```

데스크톱 앱(UI)과 백그라운드 데몬은 별도 프로세스로 분리돼 있고, 둘은 로컬 통신으로 연결된다. 데몬이 각 영상을 분석해 짧은 "지문"을 만들고, 지문을 비교해 중복 후보를 그룹으로 묶는다. 그룹 안에서는 화질·용량 기준으로 보존할 파일을 자동으로 골라 추천한다.

설계 세부는 [ARCHITECTURE.md](ARCHITECTURE.md)에 정리돼 있다.

## 시스템 요구사항

| 항목     | 최소                           | 권장                    |
| -------- | ------------------------------ | ----------------------- |
| OS       | Windows 10 (64-bit) 또는 Linux | Windows 11 / 최신 Linux |
| CPU      | 64-bit 듀얼 코어               | 쿼드 코어 이상          |
| RAM      | 4 GB                           | 8 GB 이상               |
| 저장공간 | 라이브러리와 별도로 메타데이터·썸네일용 여유 공간 | —        |
| 디스크   | HDD / SSD / NAS 모두 가능       | SSD 또는 빠른 NAS       |
| FFmpeg   | AV1·VP9 등 일부 코덱 처리에만 필요 | —                    |

- 코어가 많을수록 인덱싱이 빠르다.
- 라이브러리 원본은 복사하지 않고 제자리에서 인덱싱한다.
- macOS도 동작하지만, 일부 운영 지표가 집계되지 않는 best-effort 지원이다.

## 설치

### 방법 1 — 인스톨러 (Windows)

릴리스 인스톨러(`vidcull_x.y.z_x64-setup.exe`)를 실행한다. FFmpeg 런타임이 함께 번들돼 있어 따로 설치할 필요가 없다.

### 방법 2 — 소스에서 빌드

사전 요구: **Rust 1.85+**, **Node.js 18+**.

```bash
cd app
npm install
npm run tauri build
```

빌드 결과물은 `app/src-tauri/target/release/bundle/` 아래에 생성된다.

Windows에서 데몬·FFmpeg까지 스테이징한 **완전한 인스톨러**를 한 번에 만들려면:

```powershell
# FFmpeg 바이너리를 처음 한 번 받아둔다
.\scripts\fetch-ffmpeg.ps1

# 데몬 + FFmpeg 번들 + 인스톨러까지 빌드
.\app\scripts\build-release.ps1
```

## 사용법

1. **폴더 추가** — 설정 화면에서 감시할 디렉터리를 등록한다.
2. **자동 인덱싱** — 데몬이 알아서 파일을 스캔하고 지문을 만든다. 진행 상황은 앱 상단 상태 표시줄에서 볼 수 있다.
3. **중복 그룹 리뷰** — 탐지된 그룹을 썸네일과 신뢰도(EXACT / VERY_LIKELY / POSSIBLE)와 함께 확인한다. 화질·용량 기준으로 보존본이 자동 추천된다.
4. **안전 삭제** — 최종 확인 후 OS 휴지통으로 보낸다. 실수로 지운 경우 복원을 감지한다.
